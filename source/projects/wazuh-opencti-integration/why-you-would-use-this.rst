Why You Would Use This
======================

Your security logs contain hundreds of indicators every day — source IPs,
domains, file hashes, URLs, email addresses. Without external context,
each one is just a data point. With OpenCTI context, each one is a
decision: is this worth investigating? Is it part of a known campaign?
Who is behind it? What should we do?

This integration removes the manual pivot. Instead of copying an indicator
from Wazuh, pasting it into OpenCTI, reading a report, and making a
judgment call — the enrichment is done automatically at the moment of
detection. The analyst sees the full picture in Wazuh itself.

For production environments, this means faster triage and response. For
threat hunters working a dataset, it means bulk context without clicking
between tools. For SOAR platforms, it means actionable intelligence
flowing directly into playbooks.
