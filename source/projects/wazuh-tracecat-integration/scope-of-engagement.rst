Scope of Engagement
===================

This work has been tested mainly on **Ubuntu 24.04 LTS Server Edition**.  
All components were verified on the same environment to ensure compatibility and consistency.

The following components were included in the testing scope:

- **Wazuh Server** (Single Cluster/Multi-Cluster) – Version 4.14  
- **Tracecat Server** - Version 1.0.0-beta.27

.. note::

    While Tracecat is still under Beta Stage, it is couniuously developing with new feature and the community is also growing,
    providing exentise support and research, its capabilities doesn't limit by the term beta, rather more new anticipated features
    are under development, apart its Integration with Wazuh.
