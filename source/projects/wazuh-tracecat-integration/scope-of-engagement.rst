Scope of Engagement
===================

This work has been tested mainly on **Ubuntu 24.04 LTS Server Edition**.  
All components were verified on the same environment to ensure compatibility and consistency.

The following components were included in the testing scope:

- **Wazuh Server** (Single Cluster/Multi-Cluster) – Version 4.14  
- **Tracecat Server** - Version 1.0.0-beta.27
