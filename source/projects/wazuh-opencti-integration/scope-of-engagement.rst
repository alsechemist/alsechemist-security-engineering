Scope of Engagement
===================

This integration has been developed and tested on the following
environment:

- **Operating System:** Ubuntu 24.04 LTS
- **Wazuh Manager:** Version 4.x.x
- **OpenCTI Platform:** Version 7.x.x

.. attention::

    This project expects every instance has already been configured and deployed. The scope of this project is to integrate the two platforms, 
    and not to cover the installation and configuration of each platform. For more information on how to install and configure Wazuh Manager and 
    OpenCTI Platform, please refer to their official documentation.
